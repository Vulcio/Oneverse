**Bible**, dans les **Outils** de la barre latérale, ouvre une Bible pour lire un passage et l'ajouter à une liste. Elle y est dès qu'une de vos équipes l'active, ou l'organisation dont cette équipe fait partie (voir [L'activer](#lactiver)).

## Choisir un passage

- **Langue** : la langue des versions, la vôtre pour commencer. Tapez pour chercher, et choisissez-en n'importe quelle autre.
- **Version** : les Bibles importées sur ce serveur (**Sur ce serveur**) et, quand l'administrateur du serveur l'a configuré, les versions YouVersion dans cette langue. Tapez son nom ou son abréviation pour la trouver.
- **Livre** : tapez pour chercher, ou choisissez-le dans la liste. **Ordre biblique** range les livres comme la Bible, l'**Ancien Testament** puis le **Nouveau Testament** ; **A-Z** les range par nom. Votre choix est gardé sur cet appareil.
- **Chapitre** : choisir un livre ouvre ses chapitres, pour en choisir un.
- **Versets** : le premier et le dernier, ou aucun pour tout le chapitre.

Les noms des livres et tout le reste restent dans votre langue, quelle que soit la langue de la version. Ce que vous choisissez s'écrit dans **Passage** (« Jean 3,16-18 »). Vous pouvez aussi l'y taper, comme on l'écrit (« Ps 23,1-4 », « John 3:16 »), puis **Lire**.

Le passage s'affiche avec la mention de copyright de sa version. Un passage YouVersion a aussi un lien pour le lire sur YouVersion.

## L'ajouter à une liste

Un passage d'une Bible importée sur le serveur peut aller dans une liste. Sous le passage, **Ajouter à une liste** propose les listes à venir que vous pouvez modifier : choisissez-en une, puis son **Modèle d'écran**, et **Ajouter à la liste**. La liste garde la référence, jamais une copie du texte, et l'affiche comme un passage ajouté depuis la page de la liste (voir [Listes](/fr/sets/)). Un passage YouVersion ne peut pas encore aller dans une liste, tant que la licence de chaque version ne dit pas où son texte peut aller.

**Modèle d'écran** est le modèle avec lequel les [écrans](/fr/screens/) affichent le passage pendant qu'il est présenté ; le reste de la liste garde celui de l'écran. Ceux **Pour les Écritures** viennent d'abord - le modèle intégré **Écriture** et les modèles étiquetés **Écriture** - puis les **Autres modèles**, chacun avec le nombre de versets qu'il met par diapositive. **Le modèle de l'écran** l'affiche comme le reste de la liste, un verset par diapositive. Le dernier choisi est gardé sur cet appareil.

## L'activer

La Bible est désactivée tant qu'un administrateur ne l'active pas :

- Sur la page d'une équipe, ses administrateurs cochent **Montrer la Bible dans la barre latérale**, sous **Bible**, pour les membres de l'équipe.
- Sur la page d'une organisation, ses administrateurs font de même pour les membres de toutes ses équipes. Une équipe de cette organisation l'affiche comme déjà activée.

Les Bibles elles-mêmes viennent de l'administrateur du serveur, dans **Admin > Bibles** (voir [Admin](/fr/admin/#bibles)).
